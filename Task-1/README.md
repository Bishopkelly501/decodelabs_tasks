# DecodeLabs Task 1 – Prompt Engineering

## Overview

This project demonstrates the use of prompt engineering techniques to transform unstructured customer messages into structured JSON output.

## Project Files

- Prompt.md – Contains the prompt engineering instructions and few-shot examples.
- Output.json – Contains the structured JSON output.
- Reflection.md – Explains the approach, challenges, and lessons learned.
- README.md – Provides an overview of the project.

## Skills Demonstrated

- Prompt Engineering
- Zero-shot and Few-shot Prompting
- Delimiters
- JSON Formatting
- Structured Data Extraction
- Deterministic AI Output
